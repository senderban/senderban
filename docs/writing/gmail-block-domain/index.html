How do I block a domain in Gmail, and does it work?

Gmail's Block button works on one sender, not a whole domain. To block a domain in Gmail you make a filter on from:(@example.com) that deletes the mail. It works, but in our test on 29 October 2026 that search also caught a longer, different domain, and a from: term also matched a word in a sender's display name.

Key facts

  • Gmail's Block option works on one sender at a time and sends their future mail to Spam. Google's help page, read on 2 November 2026, describes no way to block a whole domain.
  • The free way is a filter whose sender is @example.com and whose action is to delete the mail.
  • On 29 October 2026, four ways of writing from: for one domain, brand.example here, each returned the same 21 result rows from three domains, one of them the longer domain brand.example.test.
  • In the same test a one-word from: term matched a sender through a word in the display name that is not in the address.
  • Senderban blocks single addresses on Gmail and moves their mail to Trash. It writes no domain filter there, because of this measurement.

Can I block a domain in Gmail?

Not with a button. Gmail's help page on blocking a sender (read 2 November 2026) offers Block "{sender}" in a message's More menu, for that one sender, and says all their future mail goes to Spam. It does not mention domains. What can cover a domain is a filter, the tool Google's filter help page describes for sending mail to a label, archiving, deleting, starring or forwarding it.

Gmail tool What it covers Where the mail goes
Block "{sender}" One sender Spam
Filter on from:(@example.com) Every sender the search matches, which is more than the domain (below) What you choose, for example delete

How do I block a domain in Gmail with a filter?

These are the steps on Google's filter help page (read 2 November 2026), with the domain filled in. Use your own domain where this says example.com.

  1. On your computer, open Gmail.
  2. In the search box at the top, click Show search options.
  3. Enter the criteria: put @example.com as the sender. Typed straight into the search box, that is from:(@example.com).
  4. Click Search and read the senders that come up. Look for any address that is not at the domain you meant, and for any sender that is there only because of its name.
  5. At the bottom of the search window, click Create filter.
  6. Choose what the filter does: delete the mail, or send it to a label if you would rather look before deleting.
  7. Click Create filter.

To undo it: Settings, See all settings, Filters and Blocked Addresses, then Delete next to the filter. Step 4 shows what the filter will take before it exists, so it is the step not to skip. 

from:(@example.com)

Does the filter block all emails from the domain, and only that domain?

It takes all of them and more. Gmail's filter reference defines a filter's sender criterion as "the sender's display name or email address", and says its query "supports the same query format as the Gmail search box" (read 2 November 2026). In the search box, on one real mailbox, from: matched whole words anywhere in the address, and in the display name too. No form we tried means "this domain and its subdomains".

The four forms from:(@brand.example), from:(brand.example), from:("@brand.example") and from:(+"@brand.example") returned the same 21 rows. They came from brand.example, from the longer domain brand.example.test and from news.brand.example.test. A real brand and its country domain stood where these stand-in names are. A query for a second domain also took its subdomain, so a subdomain is caught as well. Part of a word caught nothing.

Search Sender (stand-in) Matched Should a domain block take it?
from:(@brand.example) brand.example Yes Yes
from:(@brand.example) brand.example.test, a different domain Yes No
from:(@brand.example) news.brand.example.test Yes No
from:(brand.example), from:("@brand.example"), from:(+"@brand.example") The same three domains The same 21 rows As above
from:(@other.example), a second domain accounts.other.example, its subdomain Yes Yes
from:(@brand.e), from:(@rand.example) Part of a word 0 rows No
from:(@billing) Display name "Brand Billing", address without that word Yes No

So a filter on @brand.example deletes the mail of brand.example.test, which may be someone else. A domain whose name is another domain followed by more labels gets caught with it.

Is blocking one address more exact?

In what we measured, yes. A filter on one quoted address took that address and not longer addresses that end the same way. On 27 October 2026 a Gmail filter on from:("smith@example.com") that stars the mail, instead of deleting it, was tested with one mail from each sender:

Mail from (stand-in) Starred by the filter
smith@example.com Yes
john.smith@example.com No
xsmith@example.com No

Whether a quoted address also matches a display name that contains it was not tested. The cost of one address per filter is that a sender who changes address gets through.

What does Senderban do on Gmail, and what does it not do?

Senderban is a free, open-source Windows app. On a Gmail account it shows a notification for new mail with one button, Move this sender to Trash. A click adds that one address to a Gmail filter, quoted like the one above, with the Trash label, and reads the filter back to check it. In one measurement on 27 October 2026 that took 0.75 s from the click to the checked result. The filter lives on Google's server, so it also applies on your phone and in webmail.

What it does not do on Gmail, as the README states for v0.2.0:

  • No domain block. A whole-domain entry made on another account, such as an MXroute mailbox, is not applied on Gmail, and the list shows Gmail: not applied.
  • No Spam. A filter cannot file mail into Spam: the Gmail API refused the Spam label with a 400 error on 26 October 2026. A Junk or Block at server entry made on another account goes to Trash on Gmail.
  • No refusal at the server. Gmail still accepts the mail; the filter puts it in Trash.
  • Not verified by Google yet. Sign-in shows a warning, and the app is limited to 100 users until Google verifies it.

If you need one domain gone from Gmail, the filter above is the tool, after you have read its search results in step 4.

How was this measured?

Domain terms
29 October 2026, Gmail on the web, the author's own mailbox, read only: no filter was written. Each query was typed into the search box, and the sender address and display name were read from every result row.
Why the search box
Google says a filter's query uses the search box's format. Senderban's Gmail permission, message metadata, cannot run a search through the API, so the search box was the way to see what a term matches.
One address
27 October 2026, Gmail filters written through the API with a marker action (star) instead of Trash, test senders on a domain we own, one mail per case, each filter deleted right after.
Names
Real domains and addresses are replaced by reserved example names (RFC 2606).
Record
ADR 0009, section "Measured live", and the provider notes in the Senderban README.

What was not measured?

  • A domain filter acting on new mail. The domain results come from the search box, which Google says shares the filter's format; a filter at delivery was not run.
  • A display name that holds the domain itself, such as "brand.example support". The display-name match was seen with a one-word term.
  • Upper and lower case, non-English letters, and the - exclusion inside from:.
  • More than one mailbox, and more than one mail per address case. What a mailbox holds decides what a search can show.
  • Gmail's phone apps and Google Workspace admin settings.
  • Whether Google changes this later: the dates above are the dates it held.
