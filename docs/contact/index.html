Contact

Reach the maintainer through GitHub

Senderban has no support inbox. A public answer helps the next person too.

A bug, a question or an idea

Open a new GitHub issue. It is public: leave out passwords, API keys and other people's mail addresses. Say which mail provider the account is on and which Senderban version you run (the number at the bottom of the side menu in the Senderban window).

A security problem

Do not open a public issue. Use private vulnerability reporting on the repository; only you and the maintainers see it. The security policy says what to include.

Support the project

Senderban is free and open source (Apache-2.0). If it saves you time you can sponsor the maintainer on GitHub Sponsors. Sponsoring buys no features and no priority on issues.

Work with the developer

The developer's profile and how to reach them for contract work is on Work.
