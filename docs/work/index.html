What I can do for you

Desktop apps on Electron

A tray app with a sandboxed window, a strict content security policy, IPC that checks which frame is calling, and secrets kept with the operating system's own protection. Built and attested in CI, published by hand; you can verify the attestation. The installer is not code-signed yet. Security model · verify a download

Mail and OAuth integrations

Gmail API built to follow Google's Limited Use requirements (Google has not verified the app yet), Microsoft Graph, IMAP and ManageSieve, with sign-in through PKCE and a loopback redirect and the least permissions that work. What is tested where · Sieve rules on Dovecot · Outlook decision record

Security reviews

A defensive review and an attacker's pass before a release, as for Senderban 0.2.0. Two of the findings are written up here, with the fix and what it costs. The Outlook look-alike · forged DNS and passwords

Scale and performance

A scale budget as part of the change: the unit, what grows with it, the numbers at 10 and 50 units, and a share and a deadline for every shared resource. The scale budget note · ADR 0006

How I work

  • Decisions are written down with the code, with the reasoning and the cost, and updated when something is measured: 18 decision records for Senderban so far.
  • A claim is measured or it is marked as not measured. The provider table on the home page says "tested" only where a real account ran.
  • Every push runs type check, build, lint, format, tests, an identifier check and a secret scan of the whole history in CI.
