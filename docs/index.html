Senderban

Block a sender once, from the Windows notification, on every mail account you own.

Pre-alpha. Nothing works yet. There is no installer and no release. The code is the foundation only.

How it will work

A new mail arrives and a notification offers Block sender. One click writes a rule on the mail provider's own server, so the block also applies on your phone, in webmail and in whichever mail client you use. The result is shown per account and can be undone.

What it reads and writes

  • Reads only the From and Subject of a newly arrived message, on your device.
  • Never reads message bodies. There is no Senderban server in this version.
  • Writes one rule per provider, marked as its own. Your other rules are untouched.
  • The default action is reversible (Junk or Trash), never permanent delete.
