Senderban

Block a sender once, from the Windows notification, on every mail account you own.

v0.1, early release. Windows only, for MXroute and Gmail. The installer is unsigned, so Windows SmartScreen warns on first run.

Download the latest release · How to verify the download

How it works

A new mail arrives and a Windows notification offers to block the sender. One click writes a rule on the mail provider's own server, so the block also applies on your phone, in webmail and in whichever mail client you use. The block list is shared by the accounts you added (Gmail takes single addresses, no whole domains), and you can lift a block at any time.

What it reads and writes

  • Uses only the From and Subject of a newly arrived message, plus the server's spam score on IMAP accounts, on your device.
  • Never reads message bodies. There is no Senderban server in this version.
  • Writes rules on your mail provider, marked as its own, and leaves your other rules alone. The exception is the MXroute blacklist, which has no marker: Unblock removes an address there even if you had listed it yourself.
  • The default action is reversible (Junk or Trash). Block at server, on MXroute, is off until you switch it on: it refuses mail for every mailbox on that domain and can leave no copy.

Gmail

Senderban signs in to Gmail through your own Google Cloud project and asks for two permissions only: message metadata, to show the sender and subject in the notification, and basic mail settings, to create the filters that block a sender. We receive nothing: a blocked address goes only from your device to the mail accounts you added. Senderban's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
