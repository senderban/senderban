How it works

Senderban sits in the tray and does one thing. It is not an email client: it does not send, sync or download message bodies.

  1. Add your accounts

    Gmail, Outlook, MXroute, any server with ManageSieve, or plain IMAP. Type your address and Senderban finds the right way in.

  2. Mail arrives

    A notification shows the sender, the subject and, where the server adds one, the spam score. Nothing else of the mail is read.

  3. Block in one click

    Choose this sender or the whole domain. The block applies to every account you added: as a rule on the server where the provider has one, read back to confirm.

Reversible by default

Blocked mail goes to Junk or Trash. The one exception is Block at server on MXroute, which you switch on yourself: the server then refuses the mail and keeps no copy. Every block can be lifted in the Blocked senders window.

Don't ask again

Some senders you don't want to block and don't want to hear about. One choice on the notification keeps them quiet, and its own page takes them back.

Spam filter per mailbox

On a mail server that scores spam, pick a score: the server moves mail at or over it, or the notification asks you first.

Your own mail is safe

The addresses of the accounts you added are never blocked, and a whole-domain block never covers their mail domains.

What it reads and writes

  • Uses the From and Subject of a newly arrived message, plus the server's spam score where there is one, on your device. On a plain IMAP mailbox it also reads the sender of the last 30 days of the Inbox when you block someone, and keeps nothing of them.
  • Never reads message bodies. There is no Senderban server, no account and no tracking.
  • Writes only rules it can recognise as its own again: by name, by a marker in its Sieve script, or by the id Gmail gave its filter. On a server where you already run a Sieve script it adds one include line to it, after saving a copy. The MXroute blacklist has no marker: Unblock removes an address there even if you had listed it yourself.
  • Block at server, on MXroute, is off until you switch it on: it refuses mail for every mailbox on that domain and can leave no copy.

Gmail

Senderban signs in to Gmail with your Google account and asks for two permissions only: message metadata, to show the sender and subject in the notification, and basic mail settings, to create the filters that block a sender. We receive nothing: a blocked address goes only from your device to the mail accounts you added. Senderban's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Questions

Windows warns when I run the installer. Is that expected?

Yes. The installer is not code-signed yet, so SmartScreen warns on first run: choose More info, then Run anyway. Each release lists SHA-256 hashes and a build attestation, so you can check the file came from our release workflow. How to verify the download.

Gmail sign-in says Google hasn't verified this app. Why?

Google has not verified Senderban yet, so its sign-in page shows that warning and the app is limited to 100 users until it is verified. The permissions it asks for are the two in the Gmail section above.

Does it delete my mail?

Not by default. The choices are Move to Junk and Move to Trash. On MXroute there is also Block at server, off until you switch it on: the server refuses that sender's mail and keeps no copy, until you unblock. Gmail can't file mail into Spam, so there it is Move to Trash.

Does the block still work when Senderban is closed?

On Gmail, Outlook and Sieve servers, yes: the rule lives on the server. On plain IMAP accounts (iCloud, Yahoo and others) Senderban moves the mail itself, so only while it runs.

Is there a Mac or Linux version?

Not yet. Senderban is Windows only for now.

How do I uninstall it?

Rules live on your mail server, so unblock each sender first, then remove your accounts in Senderban and uninstall it from Windows Settings. Full steps.

Free, open source, no ads

Senderban is Apache-2.0 and has no account, no ads and no data to sell. If it saves you time, star the project, report what breaks, or tell a friend who is drowning in mail.
