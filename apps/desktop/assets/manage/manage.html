Blocked senders

    Gmail accounts

    Senderban signs in to Gmail through your own Google Cloud project, so nobody else holds access to your mail. In that project turn on the Gmail API, make an OAuth client of type Desktop app, and paste its ID and secret here. The secret is stored encrypted on this device. Signing in only connects the account: blocking on Gmail is not switched on yet.

      MXroute API key

      For MXroute mailboxes only. The key is stored encrypted on this device and never shown again. Senderban checks it with MXroute when you save it, and uses it only for an account where you switch it on below. Make a key at panel.mxroute.com/api-keys.php, where the server and user name are also shown; if MXroute lets you limit a key, give it the least access that works.
